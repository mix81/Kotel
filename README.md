# 🏡 Heating Pro Fazenda v5.17

Интеллектуальная система управления котельной с интерфейсом **Progressive Web App (PWA)**. Проект настроен для работы через MQTT и адаптирован под мобильные устройства и планшеты.

## ✨ Основные возможности
* **Удаленный контроль:** Мониторинг температуры воды и управление ТЭНами в реальном времени.
* **PWA Ready:** Можно установить на смартфон как отдельное приложение (без адресной строки браузера).
* **Адаптивный дизайн:** Оптимизирован под вертикальные экраны телефонов и горизонтальные экраны планшетов.
* **Безопасность:** Доступ к панели управления защищен паролем.
* **Два режима:** Поддержка автоматического управления (ПЗА) и ручного режима.

## 🚀 Быстрый запуск на GitHub Pages
1. Создайте новый публичный репозиторий.
2. Загрузите в корень следующие файлы:
   - `index.html`
   - `style.css`
   - `script.js`
   - `manifest.json`
   - `sw.js`
3. Перейдите в **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите ветку `main` и нажмите **Save**.
5. Через 1-2 минуты ваша панель будет доступна по адресу: `https://ваш-логин.github.io/название-репозитория/`

## 📲 Установка как приложение
### На iPhone/iPad (Safari):
1. Откройте ссылку вашего сайта.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой).
3. Выберите **«На экран "Домой"»**.

### На Android (Chrome):
1. Откройте ссылку в браузере.
2. Нажмите на **три точки** в углу.
3. Выберите **«Установить приложение»**.
